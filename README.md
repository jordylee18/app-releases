# GroundTruth Pro

**Desktop application for validating digital surface models against field survey measurements.**

GroundTruth Pro computes elevation deltas between survey control points and reference surfaces, providing statistical analysis, spatial visualization, and ASPRS 2024 compliance reporting for surveying and civil engineering professionals.

## Features

- **Surface Support** — GeoTIFF, LandXML, XYZ point clouds, LAS/LAZ LiDAR
- **Statistical Analysis** — RMSE, descriptive stats, tolerance band compliance
- **ASPRS 2024 Reporting** — Two-component RMSEv, normality testing, formal accuracy statements
- **Spatial Visualization** — Interactive plots with heatmaps, contours, hillshade overlays
- **Trend Analysis** — Vertical offset curves, planar trend fitting, sector grid analysis
- **Profile Analysis** — Cross-section profiles with corridor filtering
- **Outlier Detection** — Five methods including ASPRS C.9 and Local Outlier Factor
- **Dual Surface Comparison** — Side-by-side analysis of two surfaces against the same control
- **Temporal Analysis** — Multi-epoch monitoring and change detection
- **CRS Management** — EPSG-based coordinate system handling with reprojection and scale factor support
- **Export** — CSV, XLSX, and multi-page PDF reports
- **Session Management** — Save and restore full analysis sessions
